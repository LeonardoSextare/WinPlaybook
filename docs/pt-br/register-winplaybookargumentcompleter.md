# Register-WinPlaybookArgumentCompleter

Liga o autocomplete dos comandos do Ansible no terminal atual do PowerShell.
O `Install-WinPlaybook` põe uma chamada a este comando nos perfis do
PowerShell, então você só precisa dele num terminal aberto antes da
instalação.

## Sintaxe

```powershell
Register-WinPlaybookArgumentCompleter
```

---

## Exemplos

```powershell
Register-WinPlaybookArgumentCompleter
```

Veja [Usar o autocomplete](autocomplete.md).
