# Disable-WinPlaybookVSCodeExtension

Devolve os arquivos originais da extensão Ansible do VS Code, em todas as
versões que o `Enable-WinPlaybookVSCodeExtension` corrigiu. Uma versão sem as
correções fica como está.

## Sintaxe

```powershell
Disable-WinPlaybookVSCodeExtension [-WhatIf] [-Confirm]
```

---

## Exemplos

```powershell
Disable-WinPlaybookVSCodeExtension
```

O `Uninstall-WinPlaybook` também desfaz as correções.
