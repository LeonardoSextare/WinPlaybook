# Register-WinPlaybookArgumentCompleter

Turns on autocomplete for the Ansible commands in the current PowerShell
terminal. `Install-WinPlaybook` adds a call to this command to the PowerShell
profiles, so you only need it in a terminal that you opened before the
installation.

## Syntax

```powershell
Register-WinPlaybookArgumentCompleter
```

---

## Examples

```powershell
Register-WinPlaybookArgumentCompleter
```

See [Use autocomplete](autocomplete.md).
