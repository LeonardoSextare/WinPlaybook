# WinPlaybook

**Ansible on Windows, as if it were native.**

Install it and run your playbooks straight from Windows. Ansible sees your
folders, your programs, and your settings, and you don't have to change the
way you work.

> [!WARNING]
> The project is still in development and in testing. Found a problem? Open an
> [issue](https://github.com/LeonardoSextare/WinPlaybook/issues).

## Pillars

- **Native Ansible on Windows:** you use Ansible like any other Windows
  program, without having to know Linux.
- **The real Ansible:** it's the official Ansible. You write playbooks the
  same way, and the official documentation still applies.
- **Less invasive:** WinPlaybook only changes what it needs to. Your WSL
  distributions, your VS Code settings, and your SSH keys stay as they are.
- **Leaves no trace:** run `Uninstall-WinPlaybook` and everything goes back to
  how it was. If a command fails halfway, nothing is left half done.
